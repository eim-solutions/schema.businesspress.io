Install in under a minute.

SEOMarkup is currently distributed as a reviewed unpacked extension while the Chrome Web Store listing is prepared.

  1. 1
    Download and unzip

    Save the 30 KB archive and extract it locally.

  2. 2
    Open Chrome extensions

    Visit chrome://extensions and enable Developer mode.

  3. 3
    Load the extension

    Choose “Load unpacked” and select the extracted folder.

  4. 4
    Inspect a page

    Pin SEOMarkup and click it on any regular website.

What it deliberately does not claim.

  • It does not replace Google Rich Results Test or Search Console.
  • It cannot see server-side, blocked, proxied, or unfamiliar trackers.
  • It does not fetch linked images, canonical URLs, or external vocabularies.
  • It reports markup evidence—not legal compliance, ranking impact, or user intent.
