Privacy policy · Effective 11 August 2026

Choose the privacy boundary you need.

The Chrome extension keeps inspection entirely local. The website offers a separate source-only report that sends one submitted public URL to the BusinessPress server for a one-time fetch.

Extension data

  • All analysis happens locally in Chrome.
  • No scan history is stored.
  • No page content is uploaded or transmitted.
  • No accounts, advertising identifiers, analytics events, or telemetry are used.
  • Preview images stay blocked unless you choose to load them. Chrome requests only the declared image URLs directly, without a referrer.
  • Clipboard and JSON export actions happen only after you explicitly select them.

Permissions

activeTab grants temporary access to the page after a toolbar click. scripting runs the bundled analyzer in that tab. SEOMarkup requests no host permissions and cannot inspect websites continuously in the background.

Website URL inspection

  • The URL form sends one public HTTP or HTTPS URL to the BusinessPress server.
  • The server fetches that page's source HTML and returns it to the active browser tab for analysis.
  • SEOMarkup does not create an account, scan-history record, or saved report.
  • Private-network addresses, login details, non-standard ports, oversized pages, and unsafe redirects are blocked.
  • The website does not execute the target page's JavaScript or automatically load linked assets.
  • Declared social preview images load only after you explicitly choose to load them, directly from their source without a referrer.

Standard infrastructure logs may temporarily record technical request details such as IP address, the SEOMarkup endpoint path, browser user agent, response status, and timestamp for security and reliable delivery. The target URL is submitted in the request body rather than the endpoint path.

Website analytics

The public website contains no analytics, advertising pixels, account system, or contact form.

Limits

Chrome blocks extension access to browser-internal pages, the Chrome Web Store, and some protected surfaces. Tracker detection covers evidence visible in rendered markup and the browser Performance API; it does not prove that a page is tracker-free.

Contact

SEOMarkup is published by BusinessPress. Privacy enquiries can be sent through businesspress.io.
