# Design system

## Direction

A precise inspection bench: clean white working surfaces, deep ink typography, cobalt actions, and compact evidence labels. The product interface—not decorative marketing imagery—is the proof.

## Tokens

- Canvas: `#f6f8fc`
- Surface: `#ffffff`
- Ink: `#0b1f4f`
- Muted ink: `#5f6d8c`
- BusinessPress blue: `#1447e6`
- Pale blue: `#dfe8ff`
- Success: `#147a58`
- Line: `#dbe2f0`

Use the native system sans-serif stack and a native monospace stack for evidence, permissions, and markup. Avoid gradients, invented metrics, testimonial walls, oversized radii, and generic feature-icon grids.

## Signature

The evidence console is the memorable element: a URL input styled as a precise inspection instrument, followed by a verifiable receipt. The receipt distinguishes one server-fetched public page from the extension's one clicked tab and zero outbound page-data requests.

## Responsive behavior

The hero shifts from a 5/7 split to one column below 900px. At 390px, calls to action stack, proof rails wrap without horizontal scrolling, and the real popup screenshot remains fully visible.
